当你的文章躺在第三方平台的数据库里，你真的拥有它们吗？

## 纯文本的长期价值

二十年前的 `.doc` 文件今天可能已经打不开，但二十年前的 `.txt` 依然清晰可读。**纯文本是唯一被时间证明的格式**。

Markdown 在纯文本之上加了一层极薄的语义：

- 标题、列表、引用——结构清晰
- `代码`、**强调**、~~删除线~~——表达力足够
- 表格、脚注[^1]、数学公式——满足技术写作

## 版本化带来的意外之喜

把文章纳入 Git 之后，我获得了：

1. 每一次修改的完整历史
2. 随时回滚到任意版本
3. 用 `git log -p` 回看自己思考的演进

行内公式也没问题：一篇文章的阅读时长约为 $t = \frac{n}{400}$ 分钟，其中 $n$ 为字数。

$$
\text{内容价值} = \int_{0}^{T} \text{可读性}(t)\, dt
$$

[^1]: 脚注同样是纯文本，渲染时才变成链接。
