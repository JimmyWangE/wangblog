用了五年 WordPress，插件越装越多，后台越来越慢，每次大版本升级都像拆炸弹。真正让我下决心迁移的，是一次数据库损坏：**我突然意识到，自己写了五年的东西，并不真正属于我**。

## 迁移的三个动机

1. **内容主权**：文章应该是纯文本文件，可以用任何编辑器打开，可以被 Git 版本化，可以在十年后依然可读。
2. **性能**：一个只有文字和图片的博客，没理由首屏要 3 秒。
3. **可控的复杂度**：我希望整套系统简单到可以在一个周末读完全部代码。

## 技术选型

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 内容 | Markdown | 纯文本、可 diff、生态成熟 |
| 后端 | FastAPI + SQLite | 单文件数据库，备份就是复制 |
| 前端 | 原生 JS，无构建 | 十年后依然能跑 |
| 编辑器 | 所见即所得 Markdown | 写作体验接近 Typora |

> 选型原则只有一条：**任何一个组件挂掉，内容都不会丢**。

## 数据主权意味着什么

对我来说，它意味着任何时候都能在两小时内把整站搬到另一台机器上：

```bash
# 备份就是两条命令
sqlite3 wangblog.db ".backup backup-$(date +%F).db"
tar czf uploads-$(date +%F).tgz uploads/
```

## 写在最后

迁移花了三个周末。现在写作时我只关心文字本身——这大概就是一个写作者最想要的状态。
